Docs / Browsing

The explorer

Three panes: the tree on the left, documentation top right, source below it. Tab cycles focus, f zooms whichever has it, v puts the doc beside the source rather than above it.

What each pane shows

PaneContents
ExplorerThe root, its mods, recipes and aliases, plus a ⌂ root per global recipe file. The default recipe is starred; private ones are hidden until p.
DocumentationThe whole comment block above the recipe, parameters with defaults and whether they are variadic, dependencies split into those that run before and after the body, attributes, and the exact just … line to invoke it.
SourceThe recipe as written, with line numbers matching the file and highlighting for interpolations, strings, shell variables and comments. A recipe that cannot be located in its file is rebuilt from just's own dump and marked reconstructed.

Groups

A recipe carrying [group('x')] is filed under a collapsible folder inside its module — beside the modules, never instead of them, which is what just --list does too.

just-tui — groups

│▾ project/                     ← the module
││ ▸ tools/                     ← a real `mod`, untouched
││ • default ★  Show every rec… ← ungrouped recipes stay put, above the folders
││ ▾ build  2 recipes           ← [group('build')]
││ │ • compile  Build the binary
││ │ • release  Optimised build
││ ▾ data  2 recipes            ← [group('data')]
││ │ • fetch  Download the inputs
││ │ • clean  Drop the cache

The layer appears only where it divides something: a module whose recipes fall into two or more buckets, counting ungrouped as one. A module with a single group, or none, is left alone. m folds the layer away and back.

Groups are display only. A namepath never contains one, so running, submitting and config scopes are unaffected.

Search

/ matches recipe names as a fuzzy subsequence and documentation literally, and highlights the characters it matched. It matches the file name too, so /git narrows to a global git.just library and /gitlog finds one recipe inside it.

q clears the search first and quits second.

Global recipes

Every .just file in ~/.justx/ becomes its own root, marked ⌂, below the project. just --global-justfile's file is picked up too if you have one.

Global recipes run in your current directory, not in ~/.justx: just-tui passes --working-directory, so git::log acts on the repo you are standing in.
